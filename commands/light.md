使用 `film-craft` 技能，加载 `references/cinematography-lighting.md`。

布光需求：

$ARGUMENTS

交付要求：
1. **动机光源**：这场戏的光从哪来（窗 / 台灯 / 月光 / 火 / 电视屏）——必须明确
2. **灯位表**：`| 灯 | 类型 | 位置 | 功率/色温 | 附件 | 作用 |`
3. **光比**建议（2:1 / 4:1 / 8:1 / 16:1）并说明为什么这个量级匹配情绪
4. **色彩方案**：主导色、冷暖关系、暗部倾向
5. **镜头与曝光**：焦段选择、景深意图、为调色的曝光策略

硬性要求：
- 一个场景**只有一个主光方向**，多主光 = 塑料感
- 先做减法（关掉不需要的光），不要堆灯
- 涉及器材时给具体型号类别与附件（柔光布 / 黑旗 / 色纸 / 格栅）
