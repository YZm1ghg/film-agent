# 影视专业 Agent (film-agent)

一个影视创作与学术助手：把"感觉不对"翻译成**可执行的技术方案**，
并能把结论回溯到**页级原文出处**。

知识体系由**一套影视专业书籍的知识库**提炼而成；检索层面向**用户自己的书库**
（见下方「语料来源」）。

## 安装

### 方式一：下载发布包（推荐）

到 [Releases](https://github.com/YZm1ghg/film-agent/releases) 下载
`film-agent-v1.1.0.zip`，解压后放进你的插件目录：

```
<你的插件目录>/film-agent/
```

解压后应能看到 `.zcode-plugin/`、`commands/`、`skills/`、`README.md`、`LICENSE`。

### 方式二：git clone

```bash
git clone https://github.com/YZm1ghg/film-agent.git
```

放到插件目录下即可，效果与方式一相同。

### 依赖

**无第三方依赖。** 这是一个纯提示词/知识型插件——不需要 Python、Node 或任何包管理器。

> `skills/film-craft/corpus/` 下的脚本只在你想自建检索语料时才用得上，
> 那部分需要 Python 与 OCR 环境，详见「语料来源」。

### 验证安装

装上后，输入 `/film` 或直接问一句影视相关问题。
若能看到本技能被触发，即为安装成功。

## 能力

| 命令 | 用途 |
|---|---|
| `/film` | 通用入口 —— 任何影视问题 |
| `/script` | 编剧：logline、三幕结构、人物、对白、改稿诊断 |
| `/shot` | 分镜与调度：镜头表、平面图、走位、剪辑点 |
| `/light` | 摄影布光：灯位表、光比、色彩方案、器材 |
| `/lookup` | 检索原文，给出**书名 + 页码**（指向你自己的书库） |

不敲命令也可以——正常提问（"这场夜戏怎么拍""帮我改剧本""怎么拉片"）
会被自动路由到本技能。

## 子智能体

插件带一个子智能体 **`film-expert`**（`agents/film-expert.md`），三模式合一，工具受限为只读：

| 模式 | 职责 | 触发条件 |
|---|---|---|
| ① 检索 | 在书库里找原文，返回【书名+页码】逐字摘录 | 需要页码出处 |
| ② 剧本诊断 | 结构/场景/人物/对白四层体检，出问题清单 | 剧本要独立诊断 |
| ③ 分镜审校 | 镜头表逐镜 pass/fail + 证据 | 交付前质量闸门 |

工具为 `Read, Bash, Grep` —— **无 Write/Edit**，所以它只判定、只摘录，不改任何文件。
这使它天然适合当**独立质量闸门**与**上下文隔离层**（全库检索的几十条命中由它吸收）。

## 知识来源

12 个知识模块 + 8 张专题卡（`skills/film-craft/references/`、`knowledge/`），
覆盖：镜头语言、编剧、导演与表演、摄影与布光、声音设计、电影史与理论、
纪录片、制片融资、拉片分析、美学理论、10 个实操 SOP。

这些模块是**提炼后的可操作系统**，日常问答直接用它，不依赖任何外部原文。

## 语料来源（重要）

**本插件不附带、也不分发任何书籍原文。**

- 检索层（`skills/film-craft/corpus/`）里的脚本是**用户自己的工具**，
  用来把用户自己合法获得的影视专业书库建成可检索的语料。
- 插件只提供**工具与索引方法**，不含书库内容，也不含任何书籍清单。
- 完成检索所需的最小可用状态，由用户在自己的书库目录下构建。

用法（`<你的书库目录>` 是用户自己的书库位置）：

```bash
cd skills/film-craft/corpus
python run_all.py                        # 建立语料（先配置好书库目录）
python tools.py search "库里肖夫"         # 全库检索
python tools.py search "布光" --book 33   # 限定某本
python tools.py read 12 160 160          # 读某本某页
```

没有建好语料时，检索会返回空。此时 `film-expert` 会如实说明
「库内未检索到」，并给出行业通行做法 —— **绝不编造页码或原文**。

## 目录结构

```
film-agent/
├── .zcode-plugin/plugin.json
├── commands/                    五条斜杠命令
└── skills/film-craft/
    ├── SKILL.md                 主入口与路由表
    ├── references/              12 个知识模块
    ├── knowledge/               总索引 + 8 张专题卡
    └── corpus/
        ├── tools.py             检索工具（list/search/read/index）
        ├── make_cards.py        生成每本书的速览卡
        ├── run_all.py shard.py  OCR / 抽取管线（断点续跑）
        ├── launch_gpu.ps1       GPU 启动脚本
        └── out/                 语料与索引输出目录（随用户书库生成）
```

## 版权与使用说明

- 本插件**只随附原创的提炼笔记、知识模块与工具脚本**，不包含任何书籍的正文、
  扫描件或 OCR 文本。
- 使用检索功能前，用户需要**自行提供合法获得的书籍副本**，并在自己的环境中
  建立语料；插件不提供、不索要、也不代为分发这些内容。
- 文档中出现的书籍名、页码等示例，均**指向用户自己的书库**：
  页码必须来自真实检索结果，检索不到时一律回答"库内未检索到"。
- 请遵守你所在司法辖区的著作权法律，仅对你**有权使用**的资料建立检索语料。
