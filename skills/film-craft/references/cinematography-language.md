## 一、镜头 = 观众的眼睛：景别的心理学

景别不是"拍多远"，而是**观众与角色之间的心理距离**。每换一次景别，就改变一次观众的位置感。

| 景别 | 英文 | 画面内容 | 心理效果 | 典型用途 |
|---|---|---|---|---|
| 大远景 | ELS / Extreme Long Shot | 人如蝼蚁，环境吞没人 | 渺小、宿命、史诗、孤独 | 开场定调、战争全景、自然伟力 |
| 远景 | LS / Long Shot | 全身+大量环境 | 交代行动发生的空间 | 场面调度、群体动作 |
| 全景 | FS / Full Shot | 人物头顶到脚 | 身体姿态、动作完整性 | 打斗、舞蹈、走位 |
| 中全景 | MFS / Medium Full | 膝以上 | 姿态+环境平衡 | 西部片英雄式亮相 |
| 中景 | MS / Medium Shot | 腰以上 | **最中性的对话景别** | 对话、手势、日常 |
| 中近景 | MCU | 胸以上 | 亲近但仍保留距离 | 采访、严肃对话 |
| 特写 | CU / Close-Up | 肩膀以上 / 头部 | 情绪强压、亲密或窒息 | 情感高潮、反应镜头 |
| 大特写 | ECU / Extreme CU | 眼睛、嘴、手指、道具局部 | 强迫注意；放大细节为符号 | 悬念、隐喻、暴力细节 |
| 插入镜头 | Insert | 物件、时钟、信件 | 提供信息、打断节奏 | 情节信息点 |

**景别的三条铁律**

1. **景别跳跃要有理由。** 相邻两镜景别差异过小（MS→MCU）会产生"跳切"的不适感；
   差异过大（LS→ECU）则需要动机（惊吓、顿悟、暴力冲击）。中间地带最需要谨慎。
2. **不要连续用同一景别超过"意义所需"。** 同一景别重复=视觉停滞；变化=心理流动。
3. **特写的价值来自稀缺。** 一部片子里如果处处特写，就没有特写。希区柯克：**"用特写的尺寸
   来放大某个想法。"** 观众不会为一个没被"保藏"的特写买单。

## 二、摄影机运动：六种运动 + 三参数

每一种运动都必须能回答：**"为什么摄影机现在动？"** 没有动机的运动是装饰。

| 运动 | 英文 | 机械方式 | 心理学 | 何时用 |
|---|---|---|---|---|
| 摇 | Pan | 水平轴旋转 | 扫视、揭示横向空间 | 跟随对话、揭示环境 |
| 俯仰 | Tilt | 垂直轴旋转 | 上/下打量，揭示高度 | 展示建筑、威压感 |
| 推 | Dolly In / Push In | 机位向主体靠近 | 逼近、深入内心、强调 | 情绪升级、发现 |
| 拉 | Dolly Out / Pull Back | 机位远离主体 | 疏离、揭示context、结束感 | 结尾、孤独、反转 |
| 跟 | Tracking / Follow | 机位随主体平移 | 陪伴、卷入、同步 | 行走、追逐、长镜头 |
| 升降 | Crane / Boom | 垂直位移 | 超越、俯视命运 | 场景收尾、壮观揭示 |
| 手持 | Handheld | 人身体承载 | 失控、真实、焦虑、纪录片感 | 混乱、紧张、主观 |
| 斯坦尼康 | Steadicam | 稳定承载 | 流畅的"漂浮" | 长时间跟随、主观游走 |

**运动的三参数（缺一不可地描述）**

1. **类型**（推/拉/摇/移/升降/手持）
2. **幅度**（小幅度＝暗示；大幅度＝宣示）
3. **速度**（快＝紧迫/暴力；慢＝抒情/悬疑/庄严）

> 描述运动时写"**中速小幅推镜**"而不是"推镜"。含糊的运动描述会被拍摄者自由发挥，
> 结果就不是你要的镜头。

**运动的四条戒律**（镜头设计方法）

- **动机优先**：揭示新信息 / 跟随动作 / 主观视线 / 情绪转折 —— 至少占一个。
- **运动不可逆地改变观众位置**：推镜进入=观众被邀请靠近；拉镜退出=被推开。
- **运动结束要有落点**：运动应停在一个有意义的构图上（不是随便停）。
- **不要用运动代替剪辑**：该切的地方摇过去，会削弱节奏。

## 三、机位：三方关系决定一切

**摄影机-被摄体-观众，是一个三角形。** 每一次选机位，都在回答三件事：

1. **高度**：低角度＝威压/英雄/威胁；平视＝平等/中性；高角度＝弱小/被支配/俯瞰命运；
   鸟瞰＝宿命/上帝视角/图形化构图。
2. **距离**：决定景别（见上表）。
3. **朝向**：正面＝对峙/直视；3/4 侧＝最常用，有立体感；侧面＝对峙的极致（西部片对决）；
   背面＝神秘、跟随、"进入未知"。

**越肩镜头（OTS）**：电影对话的基本单位。它同时给出"说话者的肩"与"听话者的脸"，
在空间上锚定两人关系，并且保留了两个方向的对立感。

**主观镜头（POV）**：观众被迫站在角色眼睛里。极强代入，但**必须配一个"看的人"的镜头**
（否则观众不知道是谁在看）。"看-被看"成对出现，才构成主观性。

## 四、轴线（180° 规则）：电影语言的第一性原理

**定义**：两个角色（或角色与运动方向）之间有一条假想的连线，即"轴线"。摄影机必须始终
停留在轴线**同一侧**的 180° 半圆内，观众才不会产生方向混乱。

**为什么**：观众在脑中建立了一个"空间地图"。一旦摄影机越过轴线，A 在左、B 在右的关系
翻转，观众会误以为两人换了位置，注意力被打断。

**越轴的合法方式（五种）**

1. **移动摄影机**：在镜头内**可见地**越过轴线，观众看到翻转过程 → 合法。
2. **插入中性镜头**：插入一个骑轴镜头（正对轴线拍的正面/背面），再切到另一侧。
3. **插入空镜/道具**：插入一个与方向无关的镜头（地上的一支枪），再切。
4. **人物运动**：让人物自己走动，产生新的轴线。
5. **让观众迷路是有意的**：如果混乱本身就是目的（追逐、醉酒、暴力），可以越轴。

**跳轴（Jump the line）**：未经处理地越轴，是最常见的低级错误，也是最容易被有意打破的规则。

> 库里肖夫与普多夫金的"**创造性地理学**"：现实中不相邻的空间，通过剪辑可以构成观众
> 脑中一个从不存在的连续空间。轴线是这个虚构空间的黏合剂。

## 五、构图：把"画框"当成一个决策装置

**画面是一块有重量的画布。** 重力在下方，注意力在上方、中心、和"被指向"的地方。

**五种基本构图力**

| 构图法 | 原理 | 情绪 |
|---|---|---|
| 三分法 | 主体在 1/3 交点 | 平衡、自然、通用 |
| 中心构图 | 主体正中 | 对称、仪式感、压迫、库布里克式 |
| 对角线 | 主体沿对角线 | 动感、不稳定、张力 |
| **负空间** | 主体偏离，大量空白 | 孤独、无力、渺小（"小人物大空间"） |
| 框架式 | 用前景物框住主体 | 窥视、囚禁、层次（门框、窗、树） |

**视觉重量的六种来源**：面积、亮度对比、色彩饱和度、运动、人脸、和"指向性"。

**高度与地平线的意义**
- 地平线**高**（天空少，地面多）→ 人物被"压"在地面上，压抑、务实
- 地平线**低**（天空多）→ 人物被"托举"，浪漫、开阔、史诗
- 地平线**倾斜（荷兰角）**→ 失衡、不安、疯狂、危险

**构图的三条实战原则**

1. **不要平均分配**：用 1/3、2/3，避免 1/2 的死板（除非是刻意的中心对称）。
2. **引导视线**：用线条、光、景深把手引导到主体。观众不该"找"主体。
3. **留出运动方向的空间（Looking Room / Nose Room）**：角色看向右侧，就在右边留空；
   角色向右走，就在右边留空。否则观众会感到"他要撞墙了"。

## 六、景深与焦点：画面的第四维

**景深（Depth of Field）** = 画面中从近到远都清晰的那段距离。
决定景深的四要素：**光圈**（越大越浅）、**焦距**（越长越浅）、**物距**（越近越浅）、
**画幅尺寸**（越大越浅）。

**深焦（Deep Focus）**：前后景均清晰（奥逊·威尔斯《公民凯恩》）。
→ 观众可以**自己选择**看哪里；一个镜头内藏多个意义层；真实性、舞台感。

**浅焦（Shallow Focus）**：只有一层清晰。
→ **导演替观众选择**注意力；隔离主体；虚化背景＝心理孤立。

**跟焦（Follow Focus）/ 拉焦（Rack Focus）**：在同一镜头内，把焦点从 A 转到 B。
→ **"焦点转移＝注意力转移＝意义转移"**。这是最优雅的"不剪辑的剪辑"。
例：前景虚焦的酒瓶→后景清晰的人物，一次拉焦完成"人物被酒精支配"的暗示。

**景深的美学悖论**：深焦＝自由的观众、浅焦＝被引导的观众。选哪个，取决于你要观众"思考"
还是"感受"。

## 七、剪辑：把时间变成意义

**剪辑的五种基本转场**

| 转场 | 手法 | 效果 |
|---|---|---|
| 切（Cut） | 硬切 | 中性、最常用、隐形的 |
| 叠化（Dissolve） | 两镜重叠渐隐 | 时间流逝、梦幻、关联、诗意 |
| 淡入淡出（Fade） | 到黑/从黑 | 段落分隔、开始/结束 |
| 划变（Wipe） | 一画面推走另一 | 时代感、喜剧、关联对照 |
| 匹配剪辑（Match Cut） | 形状/动作/声音匹配 | 诗意跳跃时间与空间（《2001》骨头→飞船） |

**剪辑的六条语法**

1. **匹配视线（Eyeline Match）**：A 看画外 → 切到 A 所看之物。观众自动建立联系。
2. **正反打（Shot/Reverse Shot）**：对话的基本节奏，必须遵守轴线。
3. **动作匹配（Match on Action）**：在动作中途切，切点藏在动作里，切换不可见。
4. **30° 规则**：机位变化必须大于 30°，否则形似无意义的跳切。
5. **节奏（Pacing）**：镜头长度决定情绪速度。长镜＝从容/压抑；快切＝亢奋/暴力/慌乱。
   希区柯克《惊魂记》浴室戏：78 个镜头 / 45 秒。
6. **库里肖夫效应**：同一张无表情的脸 + 汤 = 饥饿；+ 棺材 = 悲伤；+ 女孩 = 欲望。
   **意义在镜头之间产生，不在镜头之内。** 这是剪辑的理论地基。

**平行剪辑（Cross-cutting）/ 交叉蒙太奇**：两条时间线交替，制造"同时发生"与迫近的碰撞。
（格里菲斯《一个国家的诞生》最后的营救段落）

**蒙太奇（Montage）一词的两种用法**
- 苏联蒙太奇学派（爱森斯坦）：镜头**冲突**产生新概念（理性蒙太奇、杂耍蒙太奇）。
- 好莱坞 montage：压缩时间的一串短镜头（训练、变美、盖房子）。

## 八、形式与风格：波德维尔的系统方法

分析任何一部电影，问四个问题：

1. **形式是什么**：这部电影由哪些**系统**构成？（叙事系统 + 风格系统）
2. **风格是什么**：摄影、剪辑、声音、场面调度四个技术轨道的**重复选择**构成了风格。
3. **风格的功能**：这些选择服务于什么？（引导注意力 / 塑造情绪 / 构建意义 / 造成美感）
4. **形式与内容的统一**：主题不是"说出来的"，是**被形式做出来的**。

**"形式主义-写实主义"是连续光谱，不是二元对立。**
- 写实主义（卢米埃尔）：摄影机是**记录**的窗口。
- 形式主义（梅里爱）：摄影机是**创造**的工具。
- 经典好莱坞：中间地带 —— 用形式主义的手法伪装成写实主义（"隐形的风格"）。

## 九、类型（Genre）：与观众的契约

类型是**制片厂与观众之间的默认合约**：观众买票时已经知道会得到什么，类型提供期待，
而**惊喜来自对期待的变奏**。

| 类型 | 核心冲突 | 必备元素 | 视觉惯例 |
|---|---|---|---|
| 西部片 | 文明 vs 野蛮 | 边疆、枪、马、小镇 | 广角全景、地平线、门框 |
| 黑色电影 | 道德堕落 | 蛇蝎美人、侦探、夜城 | 低调布光、百叶窗阴影、烟雾 |
| 恐怖片 | 秩序 vs 怪物 | 威胁、隔离空间 | 主观镜头、暗、突然运动 |
| 歌舞片 | 现实 vs 理想 | 音乐、舞、乌托邦空间 | 长镜、鲜艳、舞台光 |
| 情节剧 | 家庭与社会 | 女性主角、牺牲、泪水 | 特写、大音乐、室内 |

**类型演变三阶段**：**原始期**（建立惯例）→ **古典期**
（惯例成熟，观众与制作者共谋）→ **修正/反讽期**（打破、混合、解构惯例）。

## 十、写影评：从感受走到论证

（影评与影片分析方向）

**四层递进**

1. **描述（Description）**：发生了什么？（不是复述情节，是描述"你看见的"）
2. **分析（Analysis）**：形式上是怎么做的？（镜头、剪辑、声音、表演的具体选择）
3. **阐释（Interpretation）**：这些选择产生了什么意义？
4. **评价（Evaluation）**：它成功了吗？依据什么标准？（标准必须公开、可辩论）

**写好影评的三条纪律**

- **论点（Thesis）先行**：一篇影评是一个**论证**，不是一堆感受。第一段就该有可反驳的主张。
- **证据必须来自影片本身**：引用具体的镜头、台词、时长、构图，而不是"我觉得很感人"。
- **警惕"情节摘要症"**：摘要不是批评。摘要只在为论证服务时才出现。

**影评人的问题清单**
- 这部电影的**主导元素**是什么？（视觉？声音？表演？结构？）
- 它**重复**了什么，又在哪里**偏离**？（重复建立规则，偏离制造意义）
- 结局**解决了**什么、又**遗忘了**什么？
- 如果换一种形式（黑白→彩色、长镜→快切），意义会怎么变？

## 十一、常见错误速查

| 问题 | 症状 | 修法 |
|---|---|---|
| 跳轴 | 观众搞不清谁在哪边 | 插入中性/骑轴镜头，或用镜头内移动过轴 |
| 跳切 | 同机位同景别连切 | 机位变化 > 30°，或改景别 |
| 视线错位 | 对话者视线不"相接" | 检查两个镜头的视线高度与角度对称 |
| 空间无锚 | 观众不知身在何处 | 补一个**定场镜头（Establishing Shot）** |
| 运动无动机 | 镜头动得没道理 | 删掉运动，或找出一个动机 |
| 特写泛滥 | 特写失去冲击力 | 删掉一半特写，让保留的变强 |
| 景别单调 | 全片都是中景 | 建立"景别阶梯"：远→中→近→特 |
| 缺反应镜头 | 对话只有说话者 | 补听者的反应，情绪在**脸**上不在**嘴**上 |
