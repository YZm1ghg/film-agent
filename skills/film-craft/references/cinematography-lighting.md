## 一、 曝光三角与影像控制

**曝光三角**：光圈（Aperture / f-stop）· 快门（Shutter）· 感光度（ISO / EI）

| 参数 | 改变它会影响 | 创作后果 |
|---|---|---|
| 光圈 | 进光量 + **景深** | 大光圈（f/1.4）= 浅景深、分离主体；小光圈（f/11）= 深焦、全景清晰 |
| 快门 | 进光量 + **运动模糊** | 180° 快门（1/48 @24fps）＝ 电影感运动；慢快门＝拖尾；快的＝锐利但"视频感" |
| ISO / EI | 灵敏度 + **噪点** | 高 ISO 换暗部，代价是颗粒与宽容度 |

**10 档宽容度**：现代数字机（ARRI/RED/Sony VENICE）能记录约 14 档。**不要"正确曝光"，
要"为调色曝光"** —— 保护高光（过曝不可逆），把暗部提亮放在后期。

**关键测光点**
- **主光落点**（通常是演员靠近光源的那半边脸）
- **最亮的高光**（不要过曝到 100% IRE，留 5% 余量）
- **最深的暗部**（不要压死到 0，留 5% 细节）
- **肤色**：亚洲人肤色在 60-70% IRE 附近最自然

**曝光是风格的第一语言**：
- **低调（Low-key）**：大面积暗，小面积亮 → 悬疑、危险、黑色电影
- **高调（High-key）**：大面积亮，低对比 → 喜剧、梦幻、广告、医院
- **平光（Flat）**：对比极低 → 纪录片、新闻、写实

## 二、 三点布光：一切的语法

```
                    [ 背光 Back Light ]
                            ↓
       [ 主光 Key ] →  ▲ 主体
                           
                    [ 辅光 Fill ]  ← 从摄影机侧补
```

| 灯 | 作用 | 位置 | 强度关系 |
|---|---|---|---|
| **主光 Key** | 塑造立体感，确定光的方向与性格 | 主体 30-45° 侧上方 | 基准 |
| **辅光 Fill** | 减轻主光制造的阴影，保留暗部细节 | 摄影机另一侧，通常更柔更弱 | 主光的 1/4 ~ 1/2 |
| **背光 / 轮廓光 Back** | 把主体从背景中"切"出来 | 主体后上方 | 与主光相当或更强 |
| *（可选）* **背景光** | 分离背景与主体 | 打背景 | 独立控制 |

**光比（Lighting Ratio）**：主光 : 辅光
- **2:1** → 柔和、干净（喜剧、爱情、日戏）
- **4:1** → 有立体感（常规戏剧）
- **8:1** → 强烈、神秘（悬疑、夜戏、黑色电影）
- **16:1 以上** → 极端的明暗切割（恐怖、暴力、表现主义）

**布光的三条实操铁律**
1. **一个场景只有一个主光方向。** 多个主光=没有方向=塑料感。
2. **动机光（Motivated Light）**：光必须有"理由"（窗、灯、火、月光）。
   无动机的光会让观众潜意识不适 —— 除非是刻意的风格化。
3. **先暗后亮**：把不需要的光全部关掉，剩下的是你真正要的。
   **"布光就是减法。"**

## 三、 光的性质：硬光与柔光

| 类型 | 光源尺寸 | 阴影 | 情绪 |
|---|---|---|---|
| **硬光** | 小（裸灯、太阳直射） | 边缘锐利，对比强 | 严峻、暴力、真实、戏剧性 |
| **柔光** | 大（柔光布、反光板、天空） | 边缘模糊，过渡平滑 | 温柔、安全、美丽、商业 |

**"光源尺寸决定软硬"** ——不是灯的功率，是**发光面积相对于主体的比例**。
把 1K 灯加一层柔光布 = 更大发光面 = 更软。

**扩散与柔化的工具**
- **柔光箱 / 蝶布 Butterfly / 米菠萝**：增大发光面
- **反光板（白/银/金）**：用反射光当辅光（金色反射给暖调，银色给冷调）
- **柔光框架 Diffusion Frame**：整个场景的日光柔化
- **控光**：黑旗（Negative Fill，减光制造对比）、沙袋、格栅（Grid）

## 四、 经典布光模型

| 风格 | 特征 | 代表 | 适用 |
|---|---|---|---|
| **伦勃朗光（Rembrandt）** | 单侧主光，鼻影与颊影相接形成**三角光斑** | 荷兰绘画/传记片 | 古典、庄重、人物肖像 |
| **蝴蝶光（Butterfly / Paramount）** | 主光正上偏前，鼻下蝴蝶形小阴影 | 好莱坞黄金时代女星 | 美化、优雅、魅力 |
| **环形光（Loop）** | 主光 30-45° 侧上方，鼻影略下弯 | 最通用的肖像光 | 通用、新闻、访谈 |
| **侧光（Split / 阴阳脸）** | 主光正侧 90°，半边脸全黑 | 黑色电影、分裂人格 | 危险、矛盾、双重性 |
| **轮廓光（Rim / Kicker）** | 强背光勾边，主体近剪影 | 科幻、夜外、神秘 | 神秘、分离、造型 |
| **顶光（Top / 恐怖光）** | 从正上方打，眼窝全黑 | 恐怖片、审判 | 威胁、非人化、压迫 |
| **底光（Under / 篝火光）** | 从下往上，反常的阴影方向 | 恐怖、篝火、怪物 | 恐怖、不安（因为不自然） |

**好莱坞经典布光的现代演变**：从"三点布光 + 每盏灯都有用"转向"**实用光源（Practical）
驱动的自然主义**"（《月光男孩》《罗马》《小丑》）。现场灯（台灯、霓虹、手机屏）成为主光，
人工光只做**补充与修饰**。

## 五、 色彩：把情绪写进色谱

**色温（Kelvin）**

| 光源 | 色温 | 感觉 |
|---|---|---|
| 蜡/烛光 | ~1800K | 温暖亲密 |
| 钨丝灯 | 3200K | 暖黄，家庭感 |
| 日光（正午） | 5600K | 中性偏冷，写实 |
| 阴天/蓝调时刻 | 6500-9000K | 冷蓝，忧郁、疏离 |
| 霓虹/钠灯 | 混合（黄橙/青绿） | 都市、夜、迷离 |

**混合色温**是电影感最强的手法之一：**暖的实用光源 + 冷的窗外月色** 或反之，
同一画面里同时出现暖与冷 → 立刻产生"空间深度"与"情绪冲突"。

**色彩的三层结构（调色师思维）**
1. **色相（Hue）**：画面主导色是什么？（青橙？黄绿？品红？）
2. **饱和度（Saturation）**：鲜艳 vs 灰暗（去饱和＝现实残酷；高饱和＝风格化/梦境）
3. **明度与对比（Levels/Contrast）**：暗部的色彩倾向最定义"基调"（青暗部 vs 暖暗部）

**经典色彩方案**
- **青橙（Teal & Orange）**：肤色暖橙 + 环境青 —— 现代大片标准（人为制造冷暖对立）
- **单色主导（Monochromatic）**：《英雄》的分段色彩；《花样年华》的红
- **互补色对峙**：红 vs 绿（《天使爱美丽》）、蓝 vs 黄
- **去饱和 + 保留单色**：《辛德勒的名单》的黑白 + 红衣女孩（**色彩作为道德焦点**）

**色彩的功能**
- **建立空间**：不同地点用不同色温（家里暖、办公室冷）
- **表示时间/时代**：回忆用暖黄/褪色，现在用冷
- **表示人物状态**：角色堕落时色彩去饱和
- **制造母题**：一种颜色在关键时刻反复出现（《惊魂记》的绿、《她》的红）

**注意**：色彩方案必须**建立规则再打破**。全片青橙里突然出现一抹正红，
那就是全片最重的视觉事件。

## 六、 光学：镜头作为"人格"

**焦段的三重意义**

| 焦段 | 视角 | 空间压缩 | 心理效果 |
|---|---|---|---|
| **广角（14-28mm）** | 宽 | 拉伸纵深，夸张前后距离 | 动荡、失真、攻击性、环境吞噬人 |
| **标准（35-50mm）** | 接近人眼 | 自然 | 客观、写实、中性（最"诚实"） |
| **中长焦（85-135mm）** | 窄 | 压缩空间，背景靠近主体 | 亲密、美化、隔离（脸部特写首选） |
| **长焦（200mm+）** | 极窄 | 强烈压缩，背景如幕布 | 窥视、宿命、拥挤 |

**广角 vs 长焦的"空间感"**：同一场景，广角让两人显得**远**（他们真的隔得远），
长焦让他们显得**近**（其实很远）。**镜头决定观众对关系的感受。**

**畸变与性格**
- **广角近距离拍脸**：鼻子变大、脸变形 → 喜剧或怪诞
- **长焦拍脸**：脸扁平、五官被压缩 → 冷感、隔离
- **变形宽银幕（Anamorphic）**：椭圆散景、水平眩光（flares）、2.39:1 → "电影感"的代名词

## 七、 器材与照明

**常见灯具类型**

| 类型 | 特征 | 用途 |
|---|---|---|
| **钨丝（Tungsten）** | 3200K，全光谱，耗电发热 | 经典电影布光 |
| **HMI** | 5600K，高功率日光 | 日戏外景、大场景 |
| **LED** | 可调色温/颜色，低热 | 现代主流（轻、省、可控） |
| **荧光（Kino Flo）** | 软，低热 | 柔光主光、近距离 |
| **实用光源 Practical** | 画面内可见的灯（台灯、霓虹） | 动机光的来源 |

**控光附件速查**

| 附件 | 作用 |
|---|---|
| 柔光布 / 柔光箱 | 变软 |
| 黑旗 / 挡光板 | 减法（切掉溢光） |
| 格栅 Grid / 蜂巢 | 限制光束角度 |
| 色纸 Gel（CTO/CTB/ND） | 改色温、减光 |
| 反光板 | 免费辅光 |
| 沙袋 / C 型架 | 安全（**永远配重**） |

**现场安全与纪律**：电缆过门要压槽、灯架必配重、高温灯远离可燃物、
收工"断电-散热-装箱"三步。**现场效率 ≈ 器材归位的好习惯。**

## 八、 摄影师的准备工作清单

- [ ] **参考片（Reference）**：为每个场景找 2-3 张参考图（不是"像哪部片"，是"这个感觉"）
- [ ] **LUT / 时码测试**：现场监看的色彩方案与后期一致吗？
- [ ] **测试片（Camera Test）**：肤色的还原、暗部噪点、色彩科学
- [ ] **镜头测试**：每个焦段的畸变与散景是否可接受
- [ ] **光线计划（Lighting Plan）**：平面图上标注每个灯的位置、功率、色温、附件
- [ ] **拍摄顺序表**：按机位/光位合并场次，而不是按剧本顺序
- [ ] **备份策略**：双卡同时录（DIT）+ 每日三份备份（**3-2-1 原则**）

**摄影师的终极问题**：**"这场戏在情绪上是什么，我该怎么用光把这个情绪'量'出来？"**
