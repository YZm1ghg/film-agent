# 实战规程 · SOP 与工作流

> 可直接执行的操作规程，精炼自影视专业著作的方法论。
> 检索原文：`python tools.py search "工作流"`（语料由用户自己的书库提供）

---

## SOP-1 · 从零开始做一个短片（8 周冲刺）

**适用**：5-15 分钟剧情短片，1-3 人核心团队，极低预算。

| 周 | 任务 | 交付物 |
|---|---|---|
| W1 | **概念**：写 20 个 logline，选 1 个；写人物小传 | Logline + 人物 |
| W2 | **大纲**：8-15 节拍；做场景卡在墙上排列 | 节拍表 + 卡片 |
| W3 | **剧本**：写完（不要边写边改）；朗读 | 完整剧本 |
| W4 | **筹备**：分镜、勘景、选角、通告草稿、场地许可 | 分镜 + 计划 |
| W5 | **排练 + 试拍**：只排走位；试拍一天找问题 | 试拍素材 |
| W6 | **拍摄**：3-5 天，每天 3-5 页 | 素材 + 场记单 |
| W7 | **剪辑**：粗剪→精剪；锁画 | 精剪版 |
| W8 | **声音 + 调色 + 输出**；放映给 5 个人看并收集反馈 | 成片 |

**铁律**：**W3 结束时剧本必须定稿。** 边拍边改剧本 = 全组陪葬。

## SOP-2 · 一场戏的调度设计（30 分钟完成）

```
① 写下这场戏的意图：______ 想要什么，结果变成什么
② 画平面图：门 / 窗 / 家具 / 光源位置
③ 决定关键站位：权力关系怎么用空间表达？
④ 画出人物运动路线（箭头）
⑤ 决定摄影机位置：从哪看能同时看到关系与情绪？
⑥ 定景别阶梯：本场从 __ 景别开始，到 __ 景别结束
⑦ 标记切点：在哪个动作/视线的哪一帧切？
```

**输出**：一张平面图 + 一段 3 行文字说明。**30 分钟内做不出来说明这场戏你没想清楚。**

## SOP-3 · 拉片一个段落（45 分钟）

```
① 选定 2-3 分钟段落，记录下来时间码
② 逐镜记录：开始时码 / 时长 / 景别 / 角度 / 运动 / 内容
③ 统计：镜头总数、平均镜长、最长/最短镜
④ 做景别曲线图（横轴=时间，纵轴=景别从远到近）
⑤ 找到"异常值"（最长、最短、最奇怪的那一镜）→ 那就是导演的意图
⑥ 写 300 字：形式做了什么 → 产生什么效果 → 为什么
```

**关键**：**不看"导演想说什么"，看"影片做了什么"。**

## SOP-4 · 布光方案设计（一场夜戏内景）

```
① 动机光源（Motivated Source）：这场戏的光"来自哪里"？
   → 台灯 / 窗外的月光 / 电视屏幕 / 壁炉
② 主光（Key）：从动机光源方向打出主光，确定光比
   → 告密/危险 = 8:1；温情 = 2:1
③ 辅光（Fill）：用反光板或柔光，控制在主光的 1/4
④ 轮廓光（Back/Rim）：勾边，把人物从背景分离
⑤ 背景光：独立控制背景亮度（不要让人物"贴在"背景上）
⑥ 黑旗（Negative Fill）：切掉不需要的溢光 —— 减法
⑦ 实用光源（Practical）：让画面内的灯真的亮着（在画面里可见）
⑧ 检查：眼窝有没有光？暗部有没有细节？最亮处过曝了吗？
```

**黄金法则：先关灯，再开灯。** 把不需要的光全关掉，剩下的就是你的方案。

## SOP-5 · 剧本改写一轮（结构化）

```
PASS 1  结构稿（不动台词）
  · 删掉"删掉后故事不塌"的场景
  · 检查三幕比例：Act1 25% / Act2 50% / Act3 25%
  · 检查中点是否发生"逆转"
  · 检查每个情节点删掉后故事是否还能继续（能→不是情节点）

PASS 2  人物稿
  · 每个主要人物：Want / Need / Wound 各是什么？
  · 主角的"谎言"在什么时候被打碎？
  · 每个配角有一个功能吗？（没有→合并或删掉）

PASS 3  对白稿
  · 朗读全部对白，标出读起来别扭的句子
  · 删掉每句台词的前两个字试试
  · 找出所有"解释设定"的台词 → 改成行为或冲突

PASS 4  打磨稿
  · 目标：删掉 10% 字数，什么都不损失
  · 检查重复：同一个意思说了两遍的地方
```

## SOP-6 · 剪辑一版粗剪（从素材到第一版）

```
① 素材整理：按场次/镜号归类，改名为 "S01_T03_A" 形式
① ' 转录（纪录片必做）：所有素材转成文字，做纸面剪辑
② 顺片：按剧本顺序把所有 take 首尾相接（不修剪）→ 看到全貌
③ 结构剪辑：先解决"有没有故事"，不管节奏
   · 一场戏只留最好的 take
   · 删掉所有"角色走进走出"的无意义过程
④ 节奏剪辑：调整镜头长度，建立"呼吸"
   · 快慢交替；不要全片一个速度
   · 每个段落的结尾留一口气（多几帧）
⑤ 场景过渡：检查每个转场的逻辑（切/化/淡）
⑥ 加临时音乐：找参考音乐，感受节奏（不用于成片）
⑦ 锁画前的自检：故事清楚吗？每场戏有转折吗？结尾有力吗？
```

**粗剪的第一目标不是"好看"，是"故事成立"。**

## SOP-7 · 声音后期流程

```
① 对白剪辑（Dialogue Edit）
   · 挑最好的 take，用 room tone 填补空洞
   · 降噪 / 去齿 / 修复（iZotope RX 等）
② ADR（如需）：补录现场录不到的台词
③ Foley：脚步 / 衣服 / 道具触碰
④ 音效（Hard FX）：与画面直接相关的动作声
⑤ 声音设计（Sound Design）：非写实元素、主观声音、母题声音
⑥ 环境声（Ambience）：每场戏铺底，保证连续
⑦ 配乐：进/出点对齐画面事件
⑧ 预混（Pre-dub）：对白 / 音效 / 音乐 三条分别混
⑨ 终混（Final Mix）：以对白为基准，音乐与环境 Ducking -3dB
⑩ 母版输出：立体声 + 5.1 / 全景声
```

**检查**：关掉画面只听声音，故事还成立吗？

## SOP-9 · 影评写作（1000 字结构）

```
① 开场（100字）：一个具体的画面/细节切入，不要泛泛而谈
② 论点（150字）：这篇影评的核心主张 —— 必须可被反驳
③ 形式分析（400字）：3 个具体的技术证据支撑论点
   · 每个证据 = 时间点 + 技术选择 + 因此产生的效果
④ 反例处理（150字）：承认影片中"不符合你论点"的部分，并解释
   （这一节让文章从"感想"变成"批评"）
⑤ 结论（200字）：论点如何改变了我们对这部片/这个议题的理解
```

**禁忌**：复述情节超过 20%；只写"我觉得"；用"深刻""震撼""引人深思"这类空词。

## SOP-10 · 摄像机测试清单（开拍前必做）

- [ ] **肤色还原**：在目标光线下拍一张人脸，看肤色是否自然
- [ ] **宽容度**：故意过曝 3 档和欠曝 3 档，看后期能救回多少
- [ ] **暗部噪点**：在 ISO 1600/3200 拍暗部，看噪点形态是否可接受
- [ ] **色彩科学**：在 LOG 模式下拍色卡，做一次 LUT
- [ ] **镜头**：每个焦段拍一次（畸变、散景、眩光、最近对焦）
- [ ] **帧率与快门**：24fps 180° 基准；测试慢动作（48/96fps）
- [ ] **录音**：麦克风 + 录音机同步测试（时码）
- [ ] **备份流程**：卡→硬盘→第二硬盘，验证校验和

**测试片的成本是一天，省下的是整部片。**

## 术语速查（GB / 行业口语）

| 术语 | 含义 |
|---|---|
| **景别** | 画面中主体的大小（远/全/中/近/特） |
| **轴线 / 180°线** | 保证空间方向一致的假想连线 |
| **越轴** | 摄影机越过轴线导致方向混乱 |
| **跳切** | 同机位同景别的硬切，产生跳跃感 |
| **正反打** | 对话时交替拍摄两个方向 |
| **越肩镜** | 越过一人肩膀拍另一人的镜头 |
| **定场镜头** | 交代空间位置的全景 |
| **空镜** | 没有人物的环境镜头（转场/抒情/交代时间） |
| **段落镜头** | 一个镜头完成一个完整段落（长镜头） |
| **拉焦** | 同一镜头内改变焦点位置 |
| **光比** | 主光与辅光的强度比 |
| **低调光** | 大面积暗的布光（悬疑/黑色电影） |
| **色温** | 光的冷暖（K 值） |
| **实用光源** | 画面中可见的灯具本身 |
| **拟音** | 后期棚内重录的脚步/触碰等声音 |
| **环境声** | 场景的空间底噪 |
| **混响** | 空间反射造成的声音延续 |
| **Ducking** | 对白出现时自动压低其他音轨 |
| **故事内/外声音** | 角色能听到的 vs 只给观众的 |
| **锁定画面** | 剪辑定稿，之后不再改画面 |
| **瀑布式分配** | 收入按顺序分配给各方的分账结构 |
| **场记单** | 记录每条 take 好坏与内容 |
| **通告单** | 每日拍摄的时间/地点/人员安排表 |
