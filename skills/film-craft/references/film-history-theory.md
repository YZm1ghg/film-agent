## 一、 电影史的三个坐标轴

理解电影史，只需要同时追踪三条线：

1. **技术线**：从无声到有声、从黑白到彩色、从胶片到数字、从 2D 到 3D/VR。
2. **产业线**：从杂耍到制片厂制度（好莱坞黄金时代）→ 电视冲击 → 大片时代 → 流媒体。
3. **美学线**：写实主义 ↔ 形式主义 的永恒摆动。

**美学线的关键摆动**
```
卢米埃尔(记录) ── 梅里爱(幻术) ── 格里菲斯(叙事语法) ──
德国表现主义/法国印象派/苏联蒙太奇(1920s 形式主义高峰) ──
好莱坞经典时期(1930-50 隐形风格) ──
意大利新现实主义(1945- 写实反扑) ──
法国新浪潮(1959- 作者论+跳切) ──
新好莱坞(1967- 类型解构) ──
数字时代(1999- 虚拟与混合)
```

## 二、 四个奠基时刻

### 1. 蒙太奇学派（苏联，1920s）

- **库里肖夫实验**：证明**意义产生于镜头之间的并置**，而非单个镜头内部。
- **普多夫金**：镜头如**砖块**，累积构建意义（叙事性剪辑）。
- **爱森斯坦**：镜头如**冲突**，两个镜头的撞击产生**新概念**（辩证蒙太奇）。
  《战舰波将金号》"敖德萨阶梯"：石狮从沉睡到跃起 —— 三个静止镜头**合成**一个动作。
- **遗产**：剪辑不只是连接，而是**制造概念**的工具。

### 2. 巴赞与写实主义理论（1945-58）

- **影像本体论**：摄影的独特性是**自动生成**，它把真实"保存"下来（"木乃伊情结"）。
- **长镜头与景深**：巴赞推崇**段落镜头（Sequence Shot）**与**深焦**，因为它保留
  **现实的暧昧性**，让观众自由选择看什么 —— 而不是被剪辑喂食。
- **"蒙太奇是作弊"**：只有当一个事件的**意义不在画面内部**时才可用蒙太奇。
- **遗产**：**写实主义美学的地基**，直接影响了新现实主义、新浪潮、侯孝贤、安哲罗普洛斯。

**爱森斯坦 vs 巴赞 = 电影史上最重要的分歧**
| | 爱森斯坦 | 巴赞 |
|---|---|---|
| 镜头 | 素材单元 | 现实的切片 |
| 意义 | 由**并置**产生 | 由**画面内部**产生 |
| 观众 | 被引导 | 被信任 |
| 工具 | 蒙太奇 | 长镜头 + 景深 |

### 3. 意大利新现实主义（1945-1954）

**特征**：实景拍摄、非职业演员、自然光、长镜头、关注底层、拒绝完美结局。
**代表作**：《罗马，不设防的城市》《偷自行车的人》《大地在波动》。
**遗产**：纪录片美学进入剧情片；"**把摄影机扛到街上去**"。

### 4. 法国新浪潮（1959-1964）

- **作者论（Auteur Theory）**（特吕弗，《电影手册》）：**导演是电影的作者**，
  应当以导演为单位研究电影，而非以编剧或制片厂。
- **技术革新**：轻便摄影机 + 快速胶片 → 可以**上街拍**、**自然光拍**。
- **跳切（Jump Cut）**（戈达尔《精疲力尽》）：**故意打破连贯性剪辑**，
  揭示"电影是人工制品"。破坏轴线、打断视线、直接对观众说话。
- **遗产**：**作者论成为现代电影批评的基础**；跳切成为表达"时间断裂/焦虑"的标准手法。

## 三、 电影理论三阶段

| 阶段 | 时期 | 核心问题 | 关键概念 |
|---|---|---|---|
| **经典理论** | 1920s-60s | 电影是什么？电影的本质？ | 蒙太奇、写实主义、作者 |
| **现代理论** | 1960s-80s | 电影如何产生意义？ | 符号学、结构主义、精神分析、意识形态 |
| **当代理论** | 1980s- | 谁在观看？如何观看？ | 观众研究、女性主义、后殖民、酷儿、认知主义 |

**关键理论工具速查**

| 理论 | 核心主张 | 用它可以分析 |
|---|---|---|
| **符号学（梅茨）** | 电影是"没有语言系统的语言" | 镜头如何像词一样组合；隐喻与换喻 |
| **精神分析（劳拉·穆尔维）** | 电影满足"窥视欲"；男性凝视 | 女性在银幕上被"作为景观"；观众位置 |
| **意识形态批评（阿尔都塞/齐泽克）** | 电影再现并**再生产**主流意识形态 | 类型片如何合法化主流价值 |
| **女性主义电影理论** | "女性作为影像，男性作为观看者" | 摄影机如何被性别化；反凝视的策略 |
| **后殖民理论** | 电影是殖民话语的工具 | 东方主义、他者化、第三电影 |
| **认知主义（波德维尔）** | 观众用日常认知理解电影 | 观众如何推断、预测、被"误导" |
| **接受美学** | 意义在观众接受中完成 | 同一部片为何有不同解读 |

## 四、 电影批评的四种路径

（电影研究导论方向）

| 路径 | 核心问题 | 操作 |
|---|---|---|
| **形式主义批评** | 技巧如何构成作品？ | 分析构图、剪辑、声音、结构的**系统** |
| **作者批评（Auteurist）** | 导演的**一贯主题与风格**是什么？ | 跨作品寻找重复的母题、视觉签名 |
| **类型批评（Genre）** | 类型惯例如何被使用/变奏？ | 对比同一类型的多部作品与时代演变 |
| **意识形态/文化批评** | 影片**隐含**了什么价值与权力关系？ | 追问"谁的声音被听到，谁被消音" |

**精神分析/女性主义的经典操作**
1. 谁在**看**？（摄影机 / 角色 / 观众）
2. 谁**被看**？（被物化的对象是谁）
3. 谁有**行动力**（agency），谁只是**反应**？
4. 观看本身是否被影片**批判**（自反性）？

**批评的伦理**：任何解读必须**由文本证据支撑**。可以主观，不可以随意。

## 五、 类型电影（Genre）的历史

**类型 = 制片厂制度的产物**：制片厂发现"重复成功的最保险方式是重复本身"。
→ 类型是与观众的**契约**：观众知道会得到什么样的体验。

**类型的发展规律**
1. **原始期**：惯例尚未稳定，各种探索
2. **古典期**：惯例成熟，观众与制作者共谋，类型达到艺术巅峰
3. **修正期**：开始自我批评、混合、反思（如"修正主义西部片"）
4. **反讽/解构期**：类型成为引用与游戏的素材（后现代）

**重要类型节点**
- **西部片**：从《火车大劫案》到约翰·福特的纪念碑谷，到《不可饶恕》的挽歌。
- **黑色电影（Film Noir）**：不是导演的类型，是**批评家发明的分类**（法国影评人 1946）。
  视觉：低调布光、百叶窗、烟、雨夜城市。心理：宿命、堕落、蛇蝎美人。
- **恐怖片**：怪物是社会焦虑的**具象化**（冷战=外星人、核恐慌=哥斯拉、
  女性意识=《魔女嘉莉》）。
- **歌舞片**：现实的**中断**，乌托邦空间。

## 六、 电影史学习法

**不要背年表，建立"谱系"**：任何一个技法/类型/风格，都能追问：
1. **它出现在什么技术/产业条件下？**
2. **它回应了前人的什么？**（反叛什么、继承什么）
3. **它后来影响了谁？**

**观影的正确方法**
- **一部电影看三遍**：第一遍看故事，第二遍看形式（把声音关掉看一遍！），第三遍看细节。
- **暂停与重复**：遇到一个"感觉很强"的镜头，**停下来问为什么**。
- **比较法**：同一场戏的不同版本（不同年代的翻拍）、同一导演的两部片。

**必看的电影史节点（作者与作品）**

| 时期 | 必看 |
|---|---|
| 默片 | 《战舰波将金号》《淘金记》《卡里加里博士的小屋》《持摄影机的人》 |
| 黄金期 | 《公民凯恩》《卡萨布兰卡》《雨中曲》《迷魂记》《日落大道》 |
| 现代主义 | 《偷自行车的人》《四百击》《精疲力尽》《八部半》《奇遇》 |
| 新好莱坞 | 《邦妮与克莱德》《教父》《出租车司机》《现代启示录》 |
| 当代 | 《低俗小说》《一一》《花样年华》《月光男孩》《寄生虫》 |

**通识分析框架** —— 八个维度看任何一部电影：
摄影 · 场面调度 · 运动 · 剪辑 · 声音 · 表演 · 戏剧/叙事 · 意识形态。
**每一次分析都按这八条走一遍，不会遗漏。**
