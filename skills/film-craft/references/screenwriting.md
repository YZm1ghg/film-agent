## 一、 三幕结构：电影剧本的承重墙

悉德·菲尔德的模型（120 页 = 120 分钟黄金比）：

```
  ACT I  ────────────  ACT II ────────────────  ACT III
  建立 (0-30')          对抗 (30'-90')           结局 (90'-120')
     │                      │                        │
  情节点I                中点                    情节点II
  (约25-30')          (约60'，反转折半)          (约85-90')
     │                      │                        │
  日常世界 → 进入新世界   主角从被动变主动       最后一搏 → 解决
```

**为什么是"25/50/25"**：第一幕建立**人物与处境**，第二幕**对抗与成长**（最长，因为
冲突是电影的主体），第三幕**解决**。第二幕是最容易写垮的 —— 因此有了"中点"。

**中点（Midpoint）**：不是"事情发生在中间"，而是**主角的态度/力量对比发生逆转**的地方。
中点之前主角被动挨打；中点之后主角主动出击。中点还常常伴随**虚假的胜利或惨败**
（"一切都好了"或"一切都完了"），这正是欺骗观众的最好位置。

**三个关键问题（每一幕都要回答）**
1. 主角**想要什么**（Want，外在目标）？
2. 主角**需要什么**（Need，内在缺失）？
3. 什么东西**阻止**他？（对抗力量必须强于主角）

> **"结局的必然性，来自开端的暗示。"** 第一幕埋下的每个元素（道具、习惯、恐惧、
> 一句台词）都是第三幕的弹药。写不下去时，回头改第一幕。

## 二、 情节点（Plot Point）：故事的转向器

**情节点 = 一个事件，它"钩住"动作并把它转向另一个方向。**

- **激励事件（Inciting Incident）**：打破主角的日常平衡，故事从此无法回头。
  约在 10-15 分钟。**它必须是一个"事件"，不是"一个想法"。**
- **情节点 I**：主角**做出决定 / 被迫上路**，进入第二幕。（"跨过门槛"）
- **中点**：见上。
- **情节点 II**：全面失败 / 最黑暗时刻，促使主角做出最后的选择，进入第三幕。
- **高潮（Climax）**：最后一搏，主角用**学到的东西**解决最初的问题。
- **结局（Resolution）**：新的平衡。**应当能看出主角已经不同。**

**检验情节点是否有效**：删掉它，故事是否还能继续？如果能，它就不是情节点，是装饰。

## 三、 人物：让观众"在乎"

**人物不是形容词，是选择。** 观众通过主角在压力下的**选择**认识他 —— 所以你必须在
剧本里不断制造"必须做选择"的压力。

**三维人物**
1. **生理**：年龄、外形、健康、缺陷
2. **社会**：职业、阶层、家庭、教育
3. **心理**：欲望、恐惧、创伤、价值观

**人物的三个层次**
- **Want（外在目标）**：推动情节 —— 他追什么？
- **Need（内在需求）**：推动主题 —— 他缺什么（通常自己不知道）？
- **Wound（创伤/谎言）**：他的**错误信念**是什么？（"我不值得被爱""靠人不如靠己"）
  → **故事就是打碎这个谎言的过程。** 主角必须**付出代价**才能学到真相。

**对手（Antagonist）不是坏人，是"另一个主角"。** 最强的对抗力量来自：
- 对手有**合理的逻辑**（观众能理解他）
- 对手是主角**恐惧的具象化**（他的存在戳中主角的创伤）
- 对抗来自**内部**（最难赢的敌人是自己的谎言）

**配角的功能**：每个配角都要有**一个功能**（提供信息 / 映照主题 / 制造障碍 / 展现主角变化）。
没有功能的配角 = 删掉。

## 四、 冲突与场景：每一场都必须有"转折"

**场景 = 一个地点 + 一段时间 + 一个冲突。** 每场戏结束时，**某个东西必须改变**
（信息、关系、权力、目标、情绪）。

**场景的三个问题（进入前必答）**
1. 这场戏的**目标**是什么？（谁想要什么）
2. **障碍**是什么？
3. 结束时，**谁赢了一小步**？结果是什么（好的/坏的）？

**如果一场戏删掉后故事毫无损失 → 删掉。**

**冲突的层次**
- **外部冲突**：人 vs 人 / 人 vs 环境 / 人 vs 社会
- **内部冲突**：人 vs 自我
- **主题冲突**：价值观 vs 价值观（最好的电影在这里打）

**"是的，而且…"原则**（来自即兴喜剧，同样适用于剧本）：
不要写"然后（and then）…"，要写"因此（therefore）…"。
**因果链（But / Therefore）** 而不是 **流水账（And then）**：
> A 发生了，**因此** B 发生了，**但是** C 拦住了他，**因此** 他必须 D……

## 五、 对白：冰山与潜台词

**对白不是人物说的话，是人物"用来达成目的的工具"。**

**潜台词（Subtext）**：人物**说出口的**和**真正想要的**之间的差距。
> 经典练习：两人在争论"今晚吃什么"，实际上在争夺关系里的控制权。
> **优秀的对白写的是争吵的表面，观众听见的是底下的战争。**

**写对白六戒**
1. **不要让人物说出他的想法。** 让他在**掩饰**。
2. **不要在台词里解释设定**（"如你所知，我们是亲兄弟"）。
3. **不要写"过于聪明"的台词。** 每个人都有语言习惯、口癖、说不完整的时候。
4. **不要回答问题，要回应意图。**（问"几点了？"答"你为什么老催我？"）
5. **删掉每句台词的开头两个字**，常常更自然。
6. **对白是声音的一部分**：考虑停顿、被打断、重叠（overlap）、沉默。

**沉默是台词。** 人物不说话的那三秒钟，往往是全片最重的三秒。

## 六、 结构变体：不只三幕

| 结构 | 特征 | 代表作 |
|---|---|---|
| 三幕剧 | 最主流，好莱坞标准 | 绝大多数商业片 |
| 五幕剧 | 电视/戏剧传统，细分对抗 | 长篇剧集、史诗 |
| 英雄之旅（Hero's Journey） | 坎贝尔神话学：启程-启蒙-回归 12 阶段 | 星战、黑客帝国 |
| 救猫咪节拍表 | 15 个精确节拍（Blake Snyder） | 大量好莱坞类型片 |
| 非线性 / 拼贴 | 时间打乱，主题连接 | 《低俗小说》《记忆碎片》 |
| 环形结构 | 结尾回到开端，但意义已变 | 《暴雨将至》《燃烧》 |
| 多线交织 | 数条线在主题/时间上共振 | 《撞车》《木兰花》 |

**结构不是模板，是"观众注意力的分配方案"。** 任何结构只要能持续制造"接下来会怎样"
的悬置感，就是有效的。

## 七、 改写：剧本是改出来的

（错误清单）

**第一稿的唯一作用是"存在"。** 从第二稿开始才是写作。

**改写五步**
1. **冷置**：写完先放两周，用读者的眼睛重看。
2. **结构稿**：只改结构（删场景、并场景、移情节点）。**不动台词。**
3. **人物稿**：检查每个人物的选择是否一致、是否有弧光。
4. **对白稿**：朗读。**读出声，凡是读起来别扭的一定要改。**
5. **打磨稿**：删字。目标是"删掉 10% 的字数而什么都不损失"。

**最常见的十条致命问题**
1. 前 10 页没有激励事件 → 观众走了
2. 主角被动，全程被推着走 → 观众无法代入
3. 对手太弱 → 没有真正的冲突
4. 第二幕塌陷（重复同样的事件，赌注不升级）→ **赌注必须不断变高**
5. 人物动机不清晰 → 观众困惑
6. 台词解释设定 → 假
7. 巧合解决冲突 → 廉价（**巧合可以制造问题，不可以解决问题**）
8. 结局不能回应开端 → 结构散
9. 主题靠人物说出来 → 说教
10. 写"某个时刻很酷"的场景堆积 → 不是故事

**改写的黄金问题**
> **"这场戏删掉，故事会塌吗？"** 不会，就删。
> **"这个故事只能这么讲吗？"** 不能，就再想。

## 八、 从灵感到梗概：四步成型

1. **前提（Premise / Logline）**：一句话。**"谁，想要什么，被什么阻止，后果是什么。"**
   测试：它有趣吗？它暗示了冲突吗？它独特吗？（通常要写 20 个选出 1 个）
2. **人物小传**：主角的 Want / Need / Wound / 秘密。用**动作**写，不要用形容词。
3. **大纲（Treatment / Beat Sheet）**：8-15 个节拍，每拍一句话。**先解决结构，再写台词。**
4. **场景卡（Index Cards）**：一张卡一场戏。在墙上排列 —— 亲眼看见节奏的起伏。
   卡片的移动比文字的修改便宜一百倍。

**"知道结局，才能写好开头。"** 先写最后一幕，再回头写第一幕的伏笔。
