# 声音 · 音效 · 配乐

> 精炼自影视专业著作（声音设计方向）。
> 检索原文：`python tools.py search "混音"` / `search "音效"`

---

## 一、 电影声音的三个层次

| 层次 | 内容 | 功能 |
|---|---|---|
| **对白（Dialogue）** | 台词、旁白、气声、群杂（Walla） | 传达信息与人物关系，**永远最优先** |
| **音效（SFX / Hard Effects）** | 环境声、动作声、拟音 | 建立真实感与空间 |
| **音乐（Score）** | 配乐、歌曲、源音乐（Source） | 塑造情绪、建立主题、引导期待 |

**加上第四个隐藏层**：**静默（Silence）**。声音的缺席是最强的声音。

**声音的心理学**：观众对声音的容忍度远低于画面。
- 画面模糊 = "风格"
- 声音糟糕 = "业余"
- **"观众会用眼睛原谅你，但绝不会用耳朵原谅你。"**

---

## 二、 声音的空间：不是"加个音效"那么简单

**决定一个声音在空间中的位置的五个参数**

| 参数 | 含义 | 效果 |
|---|---|---|
| **距离（Distance）** | 声源离摄影机的远近 | 决定响度与**直达声/混响声的比例** |
| **方位（Pan）** | 左右位置 | 立体声/环绕声中的定位 |
| **混响（Reverb）** | 空间的反射 | 大厅 vs 卧室 vs 户外 = 完全不同的空间感 |
| **频率（EQ）** | 高频衰减 = 距离/遮挡 | 隔着门的声音是"闷"的（低通） |
| **电平（Level）** | 响度 | 动态范围是情绪的一部分 |

**空间一致性**：如果画面切到室内但混响还是户外的，观众会觉得"假"，
却说不出哪里不对。**混响是空间的名片。**

**主观声音（Subjective Sound）**：进入角色内心时，声音会"失真"——
耳鸣、心跳放大、环境声消失、低频轰鸣。这是最有效的**主观性工具之一**。

## 三、 拟音（Foley）：把"人"还给画面

**Foley = 在录音棚里，看着画面重新表演并录制的声音** —— 脚步、衣服摩擦、触碰、吃喝。

**为什么必须做 Foley**
1. **现场录不到**：麦克风永远对着嘴，身体的声音收不到
2. **Foley 是表演**：脚步的轻重缓急传递角色的情绪与体重
3. **Foley 建立"人的存在感"**：没有 Foley 的画面里，人物像是漂浮的鬼魂

**Foley 的三大件**
- **脚步（Footsteps）**：最基础也最重要。不同地面（木/水泥/沙/水/雪）用不同材质
- **移动（Moves）**：衣服摩擦、坐下的吱呀、掏口袋
- **细节（Specifics）**：与道具的直接互动（钥匙、杯子、刀、书页）

**Foley 的艺术**：**不是"还原真实"，是"还原感受"。**（真刀砍肉不好听，用西芹折断、
生菜撕碎、甚至掰玉米的声音替代。**"听起来对"比"真实"重要。**）

## 四、 环境声（Ambience / Room Tone）：看不见的地基

**环境声 = 一个空间的"呼吸"。** 没有环境声的段落会显得"空洞、廉价"，
即使观众意识不到它的存在。

**环境声的四种作用**
1. **建立空间**：鸟叫=森林；空调嗡鸣=办公室；回声=地下车库
2. **掩盖剪辑点**：连续的环境声让不同时间拍摄的镜头"缝合"在一起
3. **营造情绪**：低频嗡鸣（Drone）制造不安；风铃与鸟鸣制造安宁
4. **暗示画外空间**：画外传来的声音让世界"延伸到画框之外"

**Room Tone（房间声）**：每个实景**必须录 60 秒的"什么都没有"**——用来做剪辑时的
"填充"（Fill），避免声音在镜头之间出现空洞。

**5.1 / 全景声中的空间设计**
- **前左/前右**：对白与主要动作
- **中置**：对白（**80% 的对白在中置**）
- **环绕**：环境、画外空间、主观干扰
- **低频（LFE）**：冲击力（爆炸、轰鸣、心跳）

## 五、 配乐：音乐如何"做"叙事

**音乐的六种叙事功能**

| 功能 | 说明 | 例 |
|---|---|---|
| **情绪定义** | 告诉观众"该怎么感受这个画面" | 悲剧用弦乐、悬疑用不谐和音 |
| **主题标记（Leitmotif）** | 一个人物/概念有一个旋律 | 《星球大战》的"帝国主题" |
| **反讽（Contrapuntal）** | 音乐与画面**相反** | 暴力场景配童谣/华尔兹 |
| **引导期待** | 音乐提前预示即将发生的事 | 危险前的低音渐强 |
| **时间与节奏** | 音乐的节拍对齐剪辑点 | 蒙太奇段落 |
| **身份与时代** | 音乐风格建立年代/地域/阶层 | 60 年代摇滚、乡村、K-pop |

**"米老鼠化"（Mickey-Mousing）**：音乐与画面动作**逐帧同步**（动作与音符对齐）。
- 动画、喜剧常用（效果可爱/滑稽）
- 在严肃题材中过度使用会显得幼稚
- **现代趋势**：让音乐与画面"错位"，制造复杂性

**音乐出现的时机法则**
- **不要在情绪最高点起音乐** —— 在**情绪准备转向**时起（音乐"推"情绪，而不是"跟"情绪）
- **静默后再进音乐**：安静 10 秒，然后音乐进来的冲击力是直接进的三倍
- **音乐的收束点（Button）**：音乐结束的那一帧应对齐一个画面事件

**Source Music（画面内音乐）**：角色在听的音乐（收音机、演唱会）。
→ 它是**调度的道具**，可以与画面配乐形成对位。

## 六、 混音（Mixing）：让"每一样都听得见"

**混音的目标不是"每样都清楚"，而是"让观众听到该听的"。**

**优先级阶梯（对白为王）**
```
1. 对白   ◄── 永远第一位，任何冲突都让位
2. 叙事相关音效（情节性的声音）
3. 音乐
4. 环境声
5. 不相关音效
```

**关键工具**

| 工具 | 作用 |
|---|---|
| **EQ** | 让各元素占据**不同频段**（对白切掉低频给 LFE 留空间） |
| **压缩（Compression）** | 控制动态，让细节听得见 |
| **侧链（Sidechain / Ducking）** | 对白出现时，音乐/环境**自动降 3-6 dB** |
| **混响 / 延迟** | 空间与距离 |
| **自动化（Automation）** | 曲线随时间变化的手工调整 |

**频率分配速查（避免"糊"）**

| 频段 | 内容 |
|---|---|
| 20-60 Hz | 轰隆（LFE、地震、心跳） |
| 60-250 Hz | 温暖/浑浊（男低音、低音贝斯） |
| 250-500 Hz | 浑浊区（大量削减留空间） |
| 500-2k Hz | 人声基频，**清晰度区** |
| 2k-5k Hz | 临场感、穿透力（女声明亮度） |
| 5k-10k Hz | 齿音、空气感（丝——要注意去齿） |
| 10k+ Hz | 空气感/嘶嘶声 |

**"-3dB 法则"**：对白出现时，音乐与环境整体降 3dB 是专业混音的常见基准。

## 七、 声音设计（Sound Design）：超越"加音效"

**声音设计师的工作是设计"体验"，而不是收集素材。**

**六个高级手法**
1. **声音不匹配（Discrepancy）**：画面是安静的，声音是嘈杂的（或反之）→ 制造焦虑
2. **声音母题（Sonic Motif）**：一个角色/概念固定配一个声音（《大白鲨》的低音）
3. **静音的暴力**：枪响后突然**完全静音**，再用一声耳鸣代替 → 主观冲击
4. **声音前置（Sound Bridge）**：下一场的声音提前进入，衔接两个空间
5. **音效作为音乐**：把音效处理成有音高的元素（火车轰鸣变成低音持续音）
6. **反向声音（Reverse）**：把音效倒放，制造非自然的诡异感

**声音的"剪辑"**：声音的剪辑点**不必**和画面同步。声音提前或延后几帧，
可以制造"顺滑"或"突兀"的不同质感。

**《现代启示录》的直升机声 / 《2001》的呼吸声 / 《拯救大兵瑞恩》的耳鸣** ——
这些都是"声音设计改变体验"的教科书段落。

## 八、 录音现场的技术清单

- [ ] **麦克风类型**：枪麦（指向性、杆举）、领夹（Lav）、吊杆（Boom）
- [ ] **录音机与备份**：双系统录音（Separate Sound），同时录**安全轨**
- [ ] **采样率与位深**：48kHz / 24-bit（行业标准）
- [ ] **时码同步（Timecode）**：声画同步的命门；用 Tentacle/TC 发生器
- [ ] **杆举位置**：麦克风在画面外、尽量靠近嘴（距离每加倍，直达声降 6dB）
- [ ] **Room Tone**：**每换一个空间/时间，录 60 秒**
- [ ] **记录现场**：冰箱、空调、日光灯等需要关掉；记录需要后期删掉的声音
- [ ] **野线（Wild Lines）**：环境噪音大时，让演员事后补录台词（ADR）

**ADR（自动对白替换）**：现场录音不可用时，后期在录音棚配台词。
**好的 ADR 是听不出来的**，但演员往往无法复现现场的火花 —— 所以现场录音永远是第一优先。

**声音后期流程**
```
现场录音 → 对白剪辑( Dialogue Edit ) → 降噪/修复 → ADR → Foley →
音效设计 → 环境声铺底 → 配乐 → 预混( Pre-dub ) → 终混( Final Mix ) →
母版( 5.1 / 全景声 ) 
```
