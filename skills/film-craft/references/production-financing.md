# 制片 · 融资 · 制作流程

> 精炼自影视专业著作（制片与融资方向）。
> 检索原文：`python tools.py search "预算"` / `search "制片"`

---

## 一、 电影制作的五个阶段

```
开发 Development → 前期筹备 Pre-production → 拍摄 Production →
后期 Post-production → 发行 Distribution
```

**各阶段的核心任务与"最大风险"**

| 阶段 | 主要工作 | 最大风险 | 占比（低成本片） |
|---|---|---|---|
| **开发** | 剧本、融资、组建团队、定演员 | 无限拖延（"开发地狱"） | 5-10% 预算 |
| **前期** | 分镜、勘景、选角、场地、保险、通告 | 准备不足 → 拍摄超支 | 15% 时间，最省钱的地方 |
| **拍摄** | 实拍 | **每天烧钱**，不可逆 | 40-50% 预算 |
| **后期** | 剪辑、声音、调色、视效 | 反复修改、无限期 | 20-30% 预算 |
| **发行** | 影展、销售、上院线/流媒体 | 无人问津 | 常被忽略 |

**最重要的一条制片真理**
> **前期多花 1 块钱的准备，能省下拍摄期 10 块钱的补救。**

## 二、 预算：钱怎么花

**低成本剧情片（< 100 万人民币）的典型预算结构**

| 科目 | 占比 | 说明 |
|---|---|---|
| 人员（演职员酬金） | 20-30% | 低预算时**延期付款/分成**是常态 |
| 器材（摄影/灯光/录音租用） | 10-15% | 租金随拍摄天数线性增长——**压缩天数最省钱** |
| 场地与美术 | 10-15% | 实景比搭景便宜；但实景需要**转场时间** |
| 后期（剪辑/声音/调色） | 15-20% | 常被低估 |
| 交通住宿餐饮 | 10% | **每天三餐+交通是隐形杀手** |
| 保险与法务 | 5% | 不可省（意外=全组停摆） |
| 应急储备（Contingency） | **10%** | **必须留，不许动** |

**"拍摄天数"是预算的杠杆**：天数 = 场次 ÷ 每日可完成页数。
- 低成本片：**每天 3-5 页**（约 3-5 分钟成片）
- 商业片：每天 2-3 页
- **把 25 天的戏压到 20 天，省的是整组人的日薪 + 器材日租 + 餐饮交通 + 住宿**

**省钱的具体手法**
1. **合并场景**：把三个地点的戏改成同一个地点（剧本阶段就做）
2. **限制机位**：少换机位 = 少挪灯 = 一天多拍
3. **日戏为主**：夜戏在布光和加班上贵得多
4. **少用儿童与动物**：法律限制 + 不可控
5. **先拍难戏**：演员状态、天气、场地许可最脆弱的部分优先
6. **"一景多拍"**：一个实景拍多个剧本场景（换美术/换角度）

## 三、 融资：钱从哪里来

**融资渠道（从易到难）**

| 渠道 | 说明 | 代价 |
|---|---|---|
| **自有资金** | 最自由，风险自担 | 全部风险 |
| **亲友投资** | 好开口，但关系风险 | 关系可能破裂 |
| **政府/基金补贴** | 艺术片、地域题材（各国电影基金） | 申请周期长，有内容要求 |
| **预售（Pre-sale）** | 用发行权换现金 | 需要明星或类型 |
| **完片担保（Completion Bond）** | 保证影片能完成 → 换取银行贷款 | 需支付保费（3-5%） |
| **股权融资** | 投资人占股份 | 稀释收益 |
| **众筹** | 面向公众（Kickstarter 等） | 需要社群基础 |
| **税收优惠/返还** | 各地退税政策 | 需符合条件，回款慢 |

**融资的核心文书**
1. **一句话简介（Logline）** —— 让人想听下去
2. **故事梗概（Synopsis，1-2 页）** —— 完整的起承转合
3. **导演阐述（Director's Statement）** —— 为什么你要拍，怎么拍
4. **预算表与融资计划（Budget & Finance Plan）** —— 钱怎么花、还差多少
5. **团队简历与作品集（Crew & Portfolio）** —— 证明你能完成
6. **样片（Proof of Concept / Sizzle Reel）** —— 最有说服力的东西

**打动投资人的三句话**
1. **"这个故事只有你能讲。"**（独特性 / 稀缺性）
2. **"这个市场已经存在。"**（可比的成功案例 + 观众群）
3. **"风险被控制住了。"**（预算合理、团队可靠、有担保）

**投资人真正问的四个问题**
- 我要投多少？→ **多少**（How much）
- 我的钱变成什么？→ **预算**（What）
- 我什么时候能看到钱？→ **时间表**（When）
- 我能拿回多少？→ **回收机制与顺序**（How much back）

**回收顺序（Waterfall / 瀑布式分配）** —— 极其关键，必须在合同里写清楚：
```
总票房/收入 → 发行方佣金 → 影院分成 → 宣发成本 →
投资本金回收（按比例） → 利润分成（按比例） → 制片人奖金
```
**"净利润"（Net Profit）常常形同虚设**（好莱坞会计：永远不盈利）。
**争取"收入分成"（Gross Participation）而不是"利润分成"（Net）**。

## 四、 前期筹备：决定成败的清单

**核心文书**
| 文书 | 内容 | 谁用 |
|---|---|---|
| **剧本（Script）** | 定稿版本，锁定 | 全组 |
| **分镜与镜头清单** | 每场的镜头设计 | 导演/摄影 |
| **拍摄计划（Shooting Schedule）** | 按场次排列的拍摄档期 | 全组 |
| **通告单（Call Sheet）** | 每日：时间、地点、人员、场次、天气 | 全组（每天发） |
| **场景平面图** | 机位图、灯光图、演员走位 | 摄影/灯光/导演 |
| **选角表（Casting Sheet）** | 角色、要求、候选演员 | 导演/选角 |
| **场地勘景报告** | 电源、噪音、许可、转场时间 | 制片/摄影 |
| **预算表与现金流** | 每周支出预测 | 制片 |
| **保险与合同** | 演员协议、场地协议、器材保险 | 制片/法务 |

**拍摄计划的排序原则**
1. **按地点合并**（不是按剧本顺序）
2. **按机位/光位合并**（少挪灯）
3. **演员档期约束优先**（明星只有 5 天，就集中拍他的戏）
4. **难戏优先**（前三天拍最难的，因为全组体力最好）
5. **留一个缓冲日**（总天数的 10%）

**"每天 3-5 页"的现实检查**：1 页剧本 ≈ 1 分钟成片。所以**低成本长片（90分钟）
最少需要 20-25 个拍摄日**，否则一定赶工。

## 五、 拍摄现场：秩序与效率

**导演组/制片组的分工**
- **导演（Director）**：表演与画面（**只管创作**）
- **制片人（Producer）**：预算、档期、资源（**只管可行**）
- **副导演（1st AD）**：现场执行、通告、进度（**实际上的现场老板**）
- **制片主任（Line Producer / UPM）**：预算执行、人员调度
- **场记（Script Supervisor）**：连续性、镜头记录、**与场记单核对**
- **摄影指导（DP）**：画面的一切（**导演只管"要什么"，DP 管"怎么做"**）
- **DIT**：素材备份与管理（**双备份 + 校验**）

**现场的关键纪律**
1. **场记单（Script Notes）必记**：每条 take 的编号、好坏、备注。
   **没有场记单的素材 = 后期灾难。**
2. **素材双备份（3-2-1）**：至少两份物理介质 + 一处异地
3. **"最后一条"（Martini Shot）**：当日最后一个镜头，全组士气节点
4. **不要"贪心"**：一条拍完了就走。**多拍的那条通常不会用。**
5. **连续性（Continuity）**：服装、道具、光线、演员位置 —— 跳切的最大来源

**"杀青"不等于"结束"** —— 立刻做**素材整理与备份**，24 小时内完成转录。

## 六、 后期与发行

**后期流程与周期（低成本长片）**
| 阶段 | 周期 | 说明 |
|---|---|---|
| 素材整理与转录 | 1-2 周 | 转录是**看素材的唯一现实方式** |
| 粗剪（Rough Cut） | 4-8 周 | 目标是"找出故事"，允许超长 |
| 精剪（Fine Cut） | 4-8 周 | 结构定型，**锁定画面（Picture Lock）** |
| 声音（对白/Foley/音效/混音） | 3-6 周 | 锁画之后开始 |
| 配乐 | 3-6 周 | 常与声音并行 |
| 调色（Color Grading） | 1-2 周 | 需要"锁画" |
| 输出与母版 | 1 周 | DCP / ProRes / H.264 |

**发行路径**
1. **影展（Festival）** —— 首映策略：A 类影展 > 领域影展 > 本地影展
2. **销售代理（Sales Agent）** —— 负责国际销售
3. **发行商（Distributor）** —— 院线/流媒体/电视
4. **自主发行（Self-distribution）** —— 社群放映、平台直发、教育渠道

**影展提交的现实**：一个片子通常只投 10-20 个影展（免费的不投、不匹配的不投）。
**首映（Premiere）状态很重要** —— 世界首映 > 国际首映 > 地区首映。
