## 一、 经典理论与现代理论的分界

| | 经典理论（1920s-1960s） | 现代理论（1960s-） |
|---|---|---|
| **核心问题** | 电影**本质**是什么？ | 电影**如何产生意义**？ |
| **方法** | 本体论、美学 | 符号学、结构主义、精神分析 |
| **提问者** | 导演/影评人（爱森斯坦、巴赞） | 学者（梅茨、穆尔维） |
| **代表** | 蒙太奇学派、写实主义、作者论 | 符号学、意识形态、女性主义 |

## 二、 经典理论的两大阵营

### 蒙太奇学派（形式主义）
**主张**：电影的意义产生于**镜头之间的关系**，而非单个镜头。
- **库里肖夫**：证明**并置产生意义**
- **普多夫金**：镜头如**砖块**，累积构建（叙事性剪辑）
- **爱森斯坦**：镜头如**冲突**，撞击产生**新概念**（辩证蒙太奇）
- **极端结论**：**"电影不是拍摄的，是剪辑的。"**

### 写实主义（巴赞）
**主张**：电影的本质是**记录现实**，剪辑是对现实的**暴力切割**。
- **影像本体论**：摄影的**自动性**保存了真实（"木乃伊情结"）
- **推崇长镜头与景深**：保留现实的**含混性**，让观众自选
- **极端结论**：**"蒙太奇是作弊 —— 它在人的意识之外制造意义。"**

### 两者的和解
**巴赞自己也承认**：蒙太奇并非不可用，**只有在事件的"意义不在画面内部"时才可用**。
（如《战舰波将金号》的石狮，现实中不存在"石狮跃起"，所以需要蒙太奇。）

**当代共识**：**两种工具，服务于不同的目标。**
长镜头给**自由**，蒙太奇给**引导**。

## 三、 作者论（Auteur Theory）

**起源**：1954 年特吕弗在《电影手册》发表《法国电影的某种倾向》，
主张**导演是电影真正的作者**（而不是编剧或制片厂）。

**三个层次的作者性**（安德鲁·萨里斯）
1. **技术能力**（Technique）
2. **独特的个性**（Personal Style）
3. **内在的意义**（Interior Meaning）—— 由主题与风格的张力产生的"世界观"

**作者论的价值**：把 B 级片导演（希区柯克、霍克斯）提升为艺术家，**改变了电影研究的方向**。

**作者论的边界（批评）**
- 忽视编剧、摄影师、剪辑师的贡献
- "作者"概念把电影简化为"一个人的表达"
- 可能被滥用为"为任何一部烂片找借口"

**现代的做法**：把作者性视为**"一个创作网络中可辨识的一致性"**，
而不是"一个人的天才"。

## 四、 现代理论工具

### 符号学（梅茨）
- **核心**：电影是"**没有语言系统的语言**"
- **能指/所指**：画面既"是"那个东西，又"代表"那个东西（**双重性**）
- **隐喻 vs 换喻**：用 A 表示 B（相似） vs 用部分表示整体（邻近）
- **叙述层（Diegesis）**：故事内 / 故事外 / 元故事
- **"电影符号学"的贡献**：把电影分析从"感受"推向"结构"

### 结构主义与叙事学
- **普洛普的 31 个功能** → 所有民间故事共享同一套结构
- **格雷马斯的符号矩阵**：故事的深层结构是二元对立的组合
- **电影应用**：类型片的结构同源性（西部片、侦探片都是"同一故事"的变奏）

### 精神分析与"凝视"（劳拉·穆尔维）
**《视觉快感与叙事电影》（1975）的核心命题**
1. **男性凝视（Male Gaze）**：摄影机被假设为"男性的眼睛"
2. **女性作为影像（Woman as Image）**：女性被"展示"（to-be-looked-at-ness），
   男性是**看的行动者**
3. **两种快感机制**：**窥视（Scopophilia）**（把他人当作对象）
   与**自恋认同（Narcissistic Identification）**（认同银幕上的自我理想）
4. **男性无意识的恐惧**：对"阉割焦虑"的两种处理 —— **贬低/惩罚** 或 **物化/恋物**

**穆尔维之后**
- **"反凝视"（Counter-cinema）**：故意打破这种观看结构
- **女性主义电影实践**：女性导演、女性视角、女性欲望的正面表现
- **"男性凝视"也被用来分析男性被观看的方式**（动作片中的男性身体）

### 意识形态批评
- **阿尔都塞**：艺术是"意识形态国家机器"的一部分，再生产主流价值
- **"症状式阅读"（Symptomatic Reading）**：找出影片**没有说**但**暴露**的东西
  （《电影手册》对《少年林肯》的经典分析）
- **应用问题**：这部片**合法化了什么**？它**看不见什么**？

### 认知主义（波德维尔、卡罗尔）
- **反对**精神分析的"无意识"解释，主张用**日常认知**（感知、推理、情感）解释观影
- **观众不是被动的**：观众运用**图式（Schema）** 进行预测、推断、修正
- **"误导"（Misdirection）**：希区柯克式的悬念是**认知操控**的技术

### 后殖民与第三电影
- **《东方学》（萨义德）**：西方对东方的**想象性建构**（他者化）
- **第三电影（Third Cinema）**（索拉纳斯/赫蒂诺）：反好莱坞、反作者电影，
  服务于解放运动
- **应用问题**：谁在**代表**谁说话？"他者"如何被**观看**？

## 五、 影评人的理论工具箱

**分析一部电影时，可以依次问**

| 理论 | 问的问题 |
|---|---|
| 形式主义 | 技巧如何构成作品？ |
| 作者论 | 导演的一贯主题与风格是什么？ |
| 类型 | 惯例如何被遵循/变奏？ |
| 结构主义 | 深层结构是什么？（二元对立） |
| 符号学 | 意义如何被"编码"？ |
| 精神分析 | 谁在看？谁被看？欲望如何被结构？ |
| 意识形态 | 隐含了什么价值与权力关系？ |
| 女性主义 | 观看被性别化了吗？ |
| 后殖民 | 谁被代表？谁被消音？ |
| 认知主义 | 观众如何被"引导"与"误导"？ |

**最重要的原则**：**任何理论都是工具，不是答案。**
先看影片，再选工具 —— **不要为了用理论而分析影片。**

## 六、 常用理论术语表

| 术语 | 含义 |
|---|---|
| **本文（Text）** | 影片作为可分析的对象（不等于"故事"） |
| **能指/所指（Signifier/Signified）** | 表达形式 / 被表达的概念 |
| **换喻/隐喻** | 邻近性替换 / 相似性替换 |
| **叙述层（Diegesis）** | 故事世界 |
| **互文性（Intertextuality）** | 文本之间的关系（引用、戏仿） |
| **凝视（The Gaze）** | 观看行为中的权力关系 |
| **窥视（Scopophilia）** | 观看的快感 |
| **拜物教（Fetishism）** | 用物替代被压抑的对象 |
| **缝合（Suture）** | 剪辑如何把观众"缝合"进叙事位置（正反打是典型） |
| **症状式阅读** | 找出文本的"漏洞"所暴露的意识形态 |
| **自反性（Reflexivity）** | 影片对自身的暴露（元电影） |
| **间离（Alienation/Distanciation）** | 让观众"思考"而非"沉浸"（布莱希特） |

## 七、 巴赞与爱森斯坦：一场没有结束的辩论

**同一场戏，两种拍法**

||爱森斯坦 | 巴赞 |
|---|---|---|
| **工具** | 蒙太奇（切割、并置） | 长镜头 + 景深（连续、纵深） |
| **观众** | 被引导（我告诉你意味什么） | 被信任（你自己发现） |
| **现实** | 素材（可以重组） | 本体（不可切割） |
| **意义** | 在镜头之间 | 在镜头之内 |
| **风格** | 形式主义 | 写实主义 |
| **极端** | 宣传片、蒙太奇段落（《洛奇》训练） | 长镜写实、纪录片（《罗马》《四月三周两天》） |

**今天的答案**：**这不是一个二选一的问题。**
- 你要观众**感受** → 长镜（让他自己经历）
- 你要观众**理解** → 蒙太奇（把结论给他）

**在同一个片子里同时使用两者，是成熟的标志。**
（《教父》的洗礼段落：蒙太奇并置"教堂"与"屠杀"产生意义；
而单镜头内，迈克的表情变化则用长镜完整呈现。）
