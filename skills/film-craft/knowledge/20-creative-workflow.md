# 创作方法卡 · 从灵感到成片

> 综合本插件各知识模块（编剧/导演/摄影/声音）的方法论，形成的**可执行创作流程**。
> 检索原文：`python tools.py search "创作"`（语料由用户自己的书库提供）

---

## 一、 创作者的三种起点

| 起点 | 表现 | 应对 |
|---|---|---|
| **有一个画面/意象**（最常见） | "我想拍一个人在雨里站着不动" | 追问：**这个人为什么不动**？→ 从意象倒推处境 → 处境倒推故事 |
| **有一个处境/概念** | "我想拍一个关于'替代'的故事" | 追问：**最能体现"替代"的具体情境是什么**？→ 找一个具体的事件 |
| **有一个真实的经历** | 自己的故事 | **永远不要直接拍自己的经历**。改成**结构**，换掉细节（否则会自我审查、会失焦） |

**共同的第一原则**：**从"具体"出发，不从"主题"出发。**
主题是**结果**，不是起点。主题在写完之后才浮现 —— 如果它一开始就在，故事会变成传声筒。

## 二、 从灵感到 logline（30 分钟练习）

**Step 1 · 写 20 个 logline**（不要评判，全部写下来）

**Logline 公式**
> **当 ______（激励事件）发生时，一个 ______（有缺陷的特征）的 ______（人物）
> 必须 ______（目标），否则 ______（赌注/后果）。**

**举例**
- ❌ "一个关于孤独的电影"（不是 logline，是氛围）
- ✅ "当一个外卖骑手捡到一个装满现金的包，一个不敢面对女儿的父亲必须
  在两天内找到失主，否则他会失去女儿的最后一次信任。"

**Step 2 · 用自己的标准筛（不要用"好不好"筛）**
1. **能不能用一句话让人想看下去**？（有趣）
2. **冲突是内在的还是只是外部障碍**？（有深度）
3. **主角的目标是"主动追求"的吗**？（有动力）
4. **赌注是什么**？（有紧张感）
5. **这个故事只有你能讲吗**？（有独特性）

**Step 3 · 选 1 个，写出 3 个版本的结局**
（写结局能暴露故事的真实主题）→ 选出最有力量的那个 → **倒推结构**

## 三、 结构搭建：四步成型

```
① Logline（一句话）
   ↓
② 人物小传（用"行为"写，不用形容词）
   · Want（外在目标）
   · Need（内在缺失）
   · Wound（创伤/错误信念）
   · 秘密（他不愿被知道的）
   ↓
③ 节拍表（8-15 拍，每拍一句话）
   | 拍 | 内容 | 功能 | 约在页数 |
   ↓
④ 场景卡（一张卡一场戏，在桌上排列）
   · 卡上写：场景号 / 地点 / 冲突 / 结果（谁赢一小步）
   · 排完之后看"节奏曲线"：高潮在哪里？有没有塌陷？
```

**节拍表的黄金 8 拍（极简版）**
1. 日常世界（给观众一个"可以失去的东西"）
2. 激励事件（打破平衡）
3. 拒绝/犹豫（主角抗拒改变）
4. 跨过门槛（决心做出）
5. 第一次胜利（虚假的希望）
6. 中点逆转（态度/力量对比翻转）
7. 全部失去（最黑暗时刻）
8. 高潮与新的平衡

**自检**：**每一拍删掉后，故事还能继续吗？** 能 → 合并或删掉。

## 四、 场景写作：每一场都必须"改变"

**场景检查卡（写完每一场填一次）**

```
场景号：____  地点：____  时间：____
① 这场戏开始时，情况是：__________
② 谁想要什么：__________
③ 障碍是：__________
④ 结束时，情况变成：__________      ← 必须与①不同
⑤ 这一场推进了哪条线：情节 / 人物 / 主题
⑥ 如果删掉这场，故事会塌吗：会 / 不会     ← "不会"= 删掉
```

**场景里的"行动"（Action）而非"谈话"**
- 一场戏里，人物应该**在做一件事**（不只是说话）：
  收拾行李、做菜、修车、贴墙纸、打牌、搬家。
- **"做的这件事"与"说的这件事"形成张力** = 潜台词。

**场景的开头与结尾**
- **晚进早出（Enter Late, Leave Early）**：在冲突已经开始时进入，
  在最有力的台词后立刻离开。**每一场戏掐掉头尾各 20%。**

## 五、 从剧本到拍摄：转换表

**导演拿到剧本后的四份文件**

| 文件 | 内容 | 用途 |
|---|---|---|
| **场景分解表（Breakdown Sheet）** | 每场：演员、道具、服装、特效、车辆、临时演员 | 制片预算 |
| **拍摄顺序表（Shooting Schedule）** | 按地点/机位/演员档期重排 | 排期 |
| **镜头表（Shot List）** | 每一场的镜头设计 | 现场执行 |
| **灯光计划（Lighting Plan）** | 平面图 + 灯位 | 摄影/灯光 |

**"剧本 ≠ 电影"的三个关键转换**
1. **台词要变成行为**：剧本写"他们吵架"，导演要问"吵架时他们在做什么"。
2. **内心要变成可见**：剧本写"他很后悔"，导演要设计一个**动作/物件**表现后悔。
3. **时间要变成空间**：剧本写"三年过去"，导演要决定**用一个镜头还是剪接**表现。

## 六、 低预算创作的九条策略

1. **限制场景数量**：一个实景拍多个剧本场景（省钱的核心）
2. **限制时间跨度**：一天之内发生的故事最省钱
3. **限制角色数量**：2-3 个角色的戏最可控（《杀戮》）
4. **利用"看不见"**：让观众想象（库里肖夫原则）—— **比拍出来更省钱也更高级**
5. **把限制变成形式**：只有一间屋 → 拍成"封闭空间"的风格（压力、幽闭）
6. **自然光 + 一个反光板**：可以拍出非常漂亮的画面
7. **日戏为主**：夜戏的布光成本是日戏的 3 倍以上
8. **少运动**：固定机位 + 精确构图，省时间也省器材
9. **先定声音**：如果现场录音困难，设计成"无声/旁白/音乐驱动"的形式

**低预算的创作优势**：限制会**强迫风格**。
（卡拉克斯、贾木许、侯麦的很多片都是在极简条件下拍出的杰作。）

## 七、 声音先行（Sound-First）创作法

**一个被忽视的高级技巧**：**先设计声音，再设计画面。**

**方法**
1. 写一个"声音脚本"：**这个段落听起来是什么？**（不是看到什么）
2. 列出声音元素：对白 / 环境 / 音效 / 静默 / 音乐
3. 找出**声音的"主角"**（哪一条声音是这段戏的主角？）
4. 然后问：**什么画面能服务于这个声音？**

**为什么有效**
- 声音比画面**更容易在低预算下做到专业**
- 声音是**情绪的最直接通道**（先感觉到，再看到）
- **"听觉的主观性"** 是电影最强的工具之一（耳鸣、心跳、失真）

**示例**
> 段落：主角在医院走廊等待手术结果。
> **声音脚本**：空调的嗡鸣（主导，持续）；远处护士站的对讲机（间歇）；
> 脚步声（画外，渐近又远去）；**没有音乐**；主角的呼吸（很近，干）。
> **然后**：画面只需要主角的**手**和**地板**，不需要脸。

## 八、 创作自检总表（交稿/开拍前过一遍）

**剧本层**
- [ ] 前 10 页有激励事件吗？
- [ ] 主角是**主动**的吗？（还是被推着走）
- [ ] 赌注在**不断升级**吗？
- [ ] 中点有**逆转**吗？
- [ ] 配角都有**功能**吗？
- [ ] 结局**回应了开端**吗？
- [ ] 台词有**潜台词**吗？（还是都在直说）

**导演层**
- [ ] 每场戏的**意图**能用一句话说清吗？
- [ ] 空间**说了话**吗？（位置/高低/距离）
- [ ] 景别**有变化**吗？
- [ ] 摄影机**有动机**吗？
- [ ] 有没有一个**视觉母题**？

**技术层**
- [ ] 曝光是"为调色"曝的吗？（保护高光）
- [ ] 每场戏有**动机光源**吗？
- [ ] 录音有 **room tone** 吗？
- [ ] 素材**双备份**了吗？
- [ ] 场记单**记全**了吗？
